1. AI Agents Canvas Direct Edit

ai_agents_canvas_direct_edit — Package: AI Tools — Deps: ai_agents, tool, canvas, canvas_ai
Short description
Deterministic Canvas component property editing without LLM. Resolves simple prop edits from SDC schemas in <7ms at 0 tokens.
Full description (HTML for d.o.)
<p>When users make simple changes to Canvas components ("set the color to blue," "change the heading to Welcome"), the correct result is deterministic. The prop name and value can be resolved directly from the SDC component schema without any AI reasoning.</p>

<p>This module does exactly that. It reads your theme's component YAML schemas, builds prop alias and enum value maps, and resolves edits through seven match tiers:</p>

<ul>
<li><strong>Exact and alias matches:</strong> "set text_color to primary" or "set the color to blue"</li>
<li><strong>Bare value inference:</strong> Just "blue" resolves to the correct prop when unambiguous</li>
<li><strong>Relative adjustments:</strong> "bigger" or "smaller" navigates enum ordinals</li>
<li><strong>Boolean toggles:</strong> "show the header" or "hide the footer"</li>
<li><strong>Reset patterns:</strong> "reset the color" returns the prop to its default</li>
<li><strong>Compound edits:</strong> "change the heading to Welcome and set the color to blue"</li>
</ul>

<p>Anything the matcher can't resolve with certainty gets a 422 response, routing the request to the existing AI agent chain. Zero false positives by design.</p>

<h3>Key features</h3>

<ul>
<li>8 Tool API plugins with automatic MCP, CLI, and AI agent discovery</li>
<li>HTTP bridge controller at the same endpoint the Canvas frontend already calls</li>
<li>Optional MCP server submodule (JSON-RPC 2.0) for external clients</li>
<li>Schema-driven: adapts automatically when theme components change</li>
<li>Config-driven verb and alias lists for customization without patching</li>
<li>Opt-in telemetry with PII-safe defaults (SHA-256 hashing, no raw text storage)</li>
<li>Works without AI providers configured (Canvas Lite mode: deterministic edits succeed, unmatched edits return 503 instead of routing to AI)</li>
</ul>

<h3>Measured results</h3>

<p>All measurements on a 15-component demo page:</p>

<ul>
<li>Deterministic path: 0 tokens, &lt;7ms</li>
<li>AI baseline: ~101K tokens, 16.4s</li>
<li>Hit rate: 60% on 20 mixed edits, zero false positives</li>
</ul>

<p>59 kernel tests, 221 assertions. PHPCS clean (Drupal + DrupalPractice).</p>

<p>Requires: <a href="https://www.drupal.org/project/ai_agents">AI Agents</a>, <a href="https://www.drupal.org/project/tool">Tool</a>, <a href="https://www.drupal.org/project/canvas">Canvas</a>.</p>

2. Canvas AI SEO

canvas_ai_seo — Package: Drupal Canvas — Deps: canvas_ai, metatag
Short description
AI-generated Schema.org JSON-LD for Canvas pages.
Full description (HTML for d.o.)
<p>Adds structured data generation to the Canvas AI page builder. When an AI agent builds or edits a Canvas page, this module generates Schema.org JSON-LD markup based on the page content and injects it into the page response.</p>

<p>The module provides two AiFunctionCall plugins:</p>

<ul>
<li><strong>AddSchemaOrgJson:</strong> Generates Schema.org JSON-LD from the page's component tree and attaches it to the canvas page entity. The SEO agent calls this after page content is finalized.</li>
<li><strong>GetLinkableComponents:</strong> Scans the page layout for components that accept internal links (href, url props), returning a structured tree the agent can use for internal linking decisions.</li>
</ul>

<p>A <code>LayoutResponseSubscriber</code> injects the generated JSON-LD into the page response at render time, and a <code>ConfigAction</code> plugin (<code>AiContextAgentsUpdate</code>) maps ai_context items to the SEO agent during recipe installation.</p>

<p>Integrates with the <a href="https://www.drupal.org/project/metatag">Metatag</a> module for meta tag management. The JSON-LD output is validated against Schema.org vocabularies and truncated to avoid blocking page publishing for long payloads.</p>

<p>Requires: <a href="https://www.drupal.org/project/canvas">Canvas AI</a>, <a href="https://www.drupal.org/project/metatag">Metatag</a>.</p>

3. AI Google Analytics

ai_google_analytics — Package: AI — Deps: ai, ai_agents, ai_context, canvas
Short description
Deterministic GA4 benchmark evaluation for Canvas pages with AI-powered failure summaries.
Full description (HTML for d.o.)
<p>Monitors Google Analytics metrics for Canvas pages and flags pages that fall below performance benchmarks. The pass/fail decision is deterministic — PHP compares metrics against configurable thresholds. AI is used only to summarize failures for editorial review.</p>

<h3>How it works</h3>

<ol>
<li><strong>Cron fetches GA4 data:</strong> The <code>GoogleAnalyticsCronService</code> polls the GA4 Data API (last 90 days) for each monitored Canvas page and stores engaged sessions, bounce rate, and key event rate on the page entity.</li>
<li><strong>Presave evaluates benchmarks:</strong> When a Canvas page is saved, the <code>BenchmarkEvaluator</code> compares stored metrics against thresholds. No AI is involved in this step.</li>
<li><strong>AI summarizes failures:</strong> If any benchmark fails, the module invokes the <code>analytics_monitoring_agent</code> (shipped in config) to generate a human-readable summary. The admin receives an email notification.</li>
</ol>

<h3>What's included</h3>

<ul>
<li><strong>GoogleAnalytics AiFunctionCall plugin:</strong> Exposes GA data queries to any AI agent in the pipeline. Agents can request metrics for specific pages (last 90 days).</li>
<li><strong>BenchmarkEvaluator service:</strong> Deterministic threshold comparison for engaged sessions, bounce rate, and key event rate. Supports per-page overrides.</li>
<li><strong>Cron service:</strong> Polls GA4 Data API on cron and stores metrics on Canvas page entities.</li>
<li><strong>Settings form:</strong> Configure GA property ID, API credentials, global benchmark thresholds, and notification settings.</li>
<li><strong>Review controller:</strong> Displays pages that have failed benchmarks with AI-generated summaries and a link to open Canvas for remediation.</li>
<li><strong>7 base fields on Canvas pages:</strong> Monitoring toggle, 3 metric fields (engaged sessions, bounce rate, key event rate), and 3 per-page benchmark override fields.</li>
<li><strong>Shipped agent config:</strong> A pre-configured <code>analytics_monitoring_agent</code> with structured output schema for failure summaries.</li>
</ul>

<p>Requires: <a href="https://www.drupal.org/project/ai">AI</a>, <a href="https://www.drupal.org/project/ai_agents">AI Agents</a>, <a href="https://www.drupal.org/project/ai_context">AI Context</a>, <a href="https://www.drupal.org/project/canvas">Canvas</a>. Also requires the <code>google/analytics-data</code> Composer package. Google Analytics API credentials must be configured separately.</p>
